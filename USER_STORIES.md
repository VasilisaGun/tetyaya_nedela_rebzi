# User Stories(5 пользовательских сценариев):

1 Как студент, я хочу выбрать конкретную дисциплину из списка и посмотреть все оценки по ней с подробностями, чтобы понять, за какие работы они получены.
Критерии приемки: По нажатию на карточку дисциплины открывается экран этого предмета с его названием и текущим средним баллом.

2 Как студент, я хочу добавить новую оценку с указанием предмета, даты, типа работы и комментария, чтобы вести актуальный учёт успеваемости.
Критерии приемки: Форма содержит поле ввода оценки, выбор даты, выбор типа работы и необязательное поле для комментария.

3 Как студент, я хочу иметь возможность исправить параметры внесённой оценки или удалить лишнюю запись, чтобы поддерживать достоверность статистики.
Критерии приемки: 
При выборе действия “Редактировать” откроется форма, пред заполненная текущими данными этой оценки.
При изменении данных применяются те же правила валидации.
После сохранения изменений обновляется запись в списке, а также пересчитываются средний балл предмета и общий средний балл.

При нажатии на кнопку удаления появляется диалоговое окно подтверждения “Удалить?” чтобы избежать случайного стирания.
После подтверждения запись удаляется из базы данных и исчезает из интерфейса.

4 Как студент, я хочу задать желаемый средний балл по дисциплине и узнать, какую оценку нужно получить за следующую работу, чтобы спланировать свою подготовку.

Критерии приемки: Пользователь выбирает дисциплину и вводит целевой средний балл, программа рассчитывает сколько необходимо оценок до до желанного балла.

5 Как студент, я хочу самостоятельно добавлять новые учебные дисциплины и при необходимости удалять их.
Критерии приемки: Форма ввода: Обязательное заполнение “Название дисциплины” и не обязательное ФИО преподавателя.
Нельзя сохранить дисциплину без названия дисциплины.
