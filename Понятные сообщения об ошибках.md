Сообщения об ошибках или пустых полях



| Номер ситуации | Ситуация | Что должно быть при этой ситуации  |
| --- | --- | --- |
| 1 | Пустое поле в форме оценки | Сообщение объяснение - Поле “Оценка” не может оставаться пустым |
| 2 | Значение оценки вне дозволенного диапазона | Сообщение объяснение - Оценка не может быть больше “5” и меньше “2” |
| 3 | Попытка создания оценки при не одной добавленной дисциплине | Сообщение - Сначала добавьте дисциплину |
| 4 | Отсутствие добавленных дисциплин | При переходе с главного экрана на экран дисциплин откроется экран с кнопкой добавления дисциплины. На экране около кнопки надпись “Добавьте дисциплину” |
| 5 | Отсутствие оценок в дисциплине | При переходе из главного экрана на экран дисциплин будет написан минус в окне где должен показываться выходящий балл по дисциплине, а при переходе на эту дисциплину, вместо оценок будет надпись “Оценки не добавлены” |
